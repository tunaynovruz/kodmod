# Shader-lər və Materiallar

Bu səhifə GPU-da işləyən kiçik proqramlar olan shader-ləri və material/tekstura anlayışlarını izah edir. Mövzular görüntü emalı filtrlərindən fərqli olaraq səhnənin rasterizasiya mərhələsində tətbiq olunur.

## Shader Tipləri

- Vertex Shader: Hər vertex üçün icra olunur; mövqe dönüşümləri, skinning.
- Fragment (Pixel) Shader: Hər fragment üçün icra olunur; rəng, tekstura, işıqlanma hesablanır.
- Digərləri: Geometry, Tessellation, Compute (qrafikdən kənar hesablamalar üçün).

```mermaid
flowchart LR
  A[Vertex Data] --> B[Vertex Shader]
  B --> C[Rasterization]
  C --> D[Fragment Shader]
  D --> E[Frame Buffer]
```

## Uniform, Attribute və Varying

- Attribute: Vertex-ə aid məlumat (mövqe, normal, UV). Vertex shader-ə daxil olur.
- Uniform: Bütün draw çağırışı boyu sabit parametrlər (matrislər, işıq mövqeyi).
- Varying: Vertex shader-dən fragment shader-ə interpolasiya olunan dəyərlər (UV, normal).

## Teksturalar və UV Koordinatları

- UV: 2D tekstura koordinatları [0,1] diapazonunda.
- Sampler: Tekstura oxuyucu. Filtrləmə: Nearest, Linear; Wrap: Repeat, Clamp.

### Java-da tekstura nümunəsi (konseptual)

```java
class Sampler2D {
    int width, height;
    int[] rgba; // row-major, 0xAARRGGBB
    int sample(float u, float v) {
        // simple repeat
        u = u - (float)Math.floor(u);
        v = v - (float)Math.floor(v);
        int x = Math.min(width-1, Math.max(0, (int)(u * width)));
        int y = Math.min(height-1, Math.max(0, (int)(v * height)));
        return rgba[y*width + x];
    }
}
```

## Material Modelləri

- Phong/Blinn-Phong: Diffuse + Specular + Ambient komponentləri.
- PBR (Physically Based Rendering): Albedo, Roughness, Metallic, Normal/Height map; enerji qorunması, mikro-səth statistikası.

## Sadə İşıqlanma (Blinn-Phong)

```
color = ambient + diffuse * max(dot(N, L), 0) + specular * pow(max(dot(N, H),0), shininess)
```

- N: səthin normalı, L: işıq istiqaməti, H: normalized (V+L) yarımvektor.

## Məşq

- UV koordinatlarını üçbucağın daxilində barycentric interpolasiya ilə hesablayın.
- Roughness artdıqca specular lobun necə dəyişdiyini müşahidə edin.
