# Rasterizasiya vs. Ray Tracing

Bu səhifə iki əsas render üsulunu müqayisə edir. Mövzular görüntü emalı filterləri deyil, səhnənin necə render olunmasıdır.

## Rasterizasiya (GPU Pipeline)

- Üçbucaqlar ekrana proyeksiya olunur, piksel toruna rasterizə edilir.
- Çox sürətlidir, real-time oyunlar üçün standartdır.
- Kölgə/əkslər üçün əlavə texnikalar (shadow mapping, screen-space reflections) lazımdır.

## Ray Tracing

- Kamera şüaları səhnəyə atılır; obyektlə kəsişmə, əks və qırılma ilə yol izlənir.
- Daha real görüntü (global illumination, yumşaq kölgələr, caustics), lakin daha bahalıdır.
- Sürətləndirmə strukturları (BVH, KD-tree) kritikdir.

```mermaid
flowchart LR
  A[Camera Rays] --> B[Acceleration Structure (BVH)]
  B --> C{Hit?}
  C -- No --> D[Background]
  C -- Yes --> E[Shading<br/>material & lights]
  E --> F[Secondary Rays]
  F --> B
```

## Hibrid Yanaşmalar

- Rasterizasiya + Ray Traced kölgə/əks/lights (RTX).
- Denoising (temporal/spatial) ilə az nümunə sayında təmiz nəticələr.

## Sadə Ray–Sphere Kəsişməsi (Java)

```java
class Vec3 { float x,y,z; /* +, -, *, dot, normalize */ }
class Ray { Vec3 o, d; }
class Sphere { Vec3 c; float r; }

// t >= 0 üçün |o + t d - c|^2 = r^2 kvadrat tənliyi
static float intersect(Ray ray, Sphere s) {
    Vec3 oc = sub(ray.o, s.c);
    float b = dot(oc, ray.d);
    float c = dot(oc, oc) - s.r*s.r;
    float disc = b*b - c; // a = 1 üçün (d normallaşdırılıb)
    if (disc < 0) return -1f;
    float t = -b - (float)Math.sqrt(disc);
    return t >= 0 ? t : -1f;
}
```

## Performans Qeydləri

- Rasterizasiya: üçbucaq doldurma və Z-buffer bottleneck ola bilər.
- Ray tracing: traversal + şüa–primitive kəsişməsi; BVH keyfiyyəti həlledicidir.
