# Grafik Renderinq Boru Xətti (Pipeline)

Bu bölmə real-time kompüter qrafikasında ən çox istifadə olunan rasterizasiya əsaslı boru xəttini izah edir. Mövzular görüntü emalı (image processing) mövzularını təkrarlamır; burada əsas fokus 3D səhnənin 2D ekrana proyeksiyası və GPU mərhələləridir.

## Ümumi Mərhələlər

```mermaid
flowchart LR
  A[Model Məlumatı<br/>(Vertex, Normal, UV)] --> B[Vertex Shader]
  B --> C[Primitive Assembly<br/>(Triangles/Lines)]
  C --> D[Clipping & Perspective Divide]
  D --> E[Screen Mapping]
  E --> F[Rasterization]
  F --> G[Fragment Shader]
  G --> H[Per-fragment Testlər<br/>(Depth, Stencil, Alpha)]
  H --> I[Blending]
  I --> J[Frame Buffer]
```

- Vertex Shader: Model koordinatlarından dünya → görünüş (view) → proyeksiya məkanına keçid, skelet animasiyası (skin).
- Rasterization: Üçbucaqlardan piksel şəbəkəsinə fragmentlər yaradılır.
- Fragment Shader: İşıqlanma, material, tekstura nümunələmə (sampling).
- Testlər/Blending: Depth test Z-buffer ilə, stencil effektlər, alpha blending.

## Koordinat Sistemləri və Matrislər

- Model space → World space → View space → Clip space → NDC → Screen space.
- Homogen koordinatlar (vec4) və 4×4 matrislər istifadə olunur.

### Java ilə sadə 4×4 matris tətbiqi

```java
// Sadə 4x4 matris və vektora tətbiq (heç bir kitabxanasız)
class Mat4 {
    float[][] m = new float[4][4];
    static Mat4 identity() {
        Mat4 I = new Mat4();
        for (int i = 0; i < 4; i++) I.m[i][i] = 1f;
        return I;
    }
    static Mat4 translation(float x, float y, float z) {
        Mat4 t = identity();
        t.m[0][3] = x; t.m[1][3] = y; t.m[2][3] = z;
        return t;
    }
    static Mat4 perspective(float fovRad, float aspect, float zNear, float zFar) {
        Mat4 p = new Mat4();
        float f = 1f / (float)Math.tan(fovRad/2f);
        p.m[0][0] = f/aspect;
        p.m[1][1] = f;
        p.m[2][2] = (zFar+zNear)/(zNear - zFar);
        p.m[2][3] = (2*zFar*zNear)/(zNear - zFar);
        p.m[3][2] = -1f;
        return p;
    }
    static float[] mul(Mat4 a, float[] v) { // v = [x,y,z,w]
        float[] r = new float[4];
        for (int i = 0; i < 4; i++)
            r[i] = a.m[i][0]*v[0] + a.m[i][1]*v[1] + a.m[i][2]*v[2] + a.m[i][3]*v[3];
        return r;
    }
}
```

## Dərinlik (Z-Buffer) və Niyə Vacibdir?

- Hər piksel üçün minimal dəyər saxlanılır: daha yaxın fragment qalır.
- Artefakt: Z-fighting — yaxın səthlərdə rəqəmsal yuvarlaqlaşma səbəbi ilə titrəmə; həll: `polygon offset`, düzgün near/far planı.

## Multisampling və Antialiasing

- MSAA: Hər piksel üçün çoxsaylı nümunələr, kənarları hamarlayır.
- Post-process AA (FXAA, TAA) görüntü emalı kateqoriyasına yaxın olsa da burada yalnız render sonrası mərhələ kimi qeyd olunur.

## Qısa Məşq

- Model matrisini döndürmə + translasiya ilə tərtib edin.
- Perspective proyeksiya ilə vertex-i klip məkanına keçirin və w ilə bölün (NDC).
