# Xidmət və Yerləşdirmə Modelləri (IaaS, PaaS, SaaS)

## Xidmət Modelləri

- IaaS: İnfrastruktur – VM, şəbəkə, disk (məs. AWS EC2, EBS, VPC)
- PaaS: Platforma – tətbiq hostinqi, runtime, autoscaling (məs. Elastic Beanstalk, Heroku)
- SaaS: Hazır proqram – istifadəçi səviyyəsində xidmətlər (məs. Gmail, Salesforce)
- FaaS/Serverless: Funksiya icrası, hadisə əsaslı ödəniş (məs. AWS Lambda)

## Yerləşdirmə Modelləri

- Public Cloud: Ümumi infrastrukturda tenant kimi işləmək
- Private Cloud: Şirkət daxili bulud (OpenStack, VMware)
- Hybrid Cloud: On-prem + public bulud inteqrasiyası
- Multi-Cloud: Bir neçə provider ilə vendor lock-in riskini azaltmaq

## Hansını Seçməli?

- Tələblər: gecikmə, uyğunluq (compliance), xərc, komanda bacarığı.
- Əməliyyat yükü: PaaS/SaaS əməliyyat xərclərini azaldır, IaaS daha çox çeviklik verir.
