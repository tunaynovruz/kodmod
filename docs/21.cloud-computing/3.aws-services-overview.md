# AWS Xidmətlərinə Ümumi Baxış

Bu səhifə AWS-in əsas məhsullarını kateqoriyalar üzrə və məqsədləri ilə qısa təqdim edir.

## Hesablama (Compute)

- EC2: Ümumi məqsədli VM-lər
- Lambda: Serverless funksiya icrası
- ECS/EKS: Konteyner orkestrasiyası (Fargate ilə serverless konteyner)
- Elastic Beanstalk: PaaS tətbiq hostinqi
- Batch: Batch işlərinin idarəsi

## Saxlama (Storage)

- S3: Obyekt saxlama (versiyalama, lifecycle, Glacier arxiv)
- EBS: EC2 üçün blok saxlama disk
- EFS: Paylaşılan fayl sistemi (NFS)
- FSx: Performant fayl sistemləri (Lustre, NetApp ONTAP)

## Məlumat Bazaları (Databases)

- RDS: İdarə olunan münasibət bazaları (PostgreSQL, MySQL, Aurora və s.)
- DynamoDB: Tam idarə olunan NoSQL key-value/document
- ElastiCache: Redis/Memcached keş
- Neptune: Qraf bazası
- DocumentDB: MongoDB uyğun sənəd bazası
- OpenSearch: Axtarış və analitika

## Şəbəkə və Məzmun Paylanması (Networking & CDN)

- VPC: İzolyasiya olunmuş virtual şəbəkə
- ELB/ALB/NLB: Yük balanslaşdırıcılar
- Route 53: DNS və health check
- CloudFront: CDN
- API Gateway: API-lərin idarəsi və proxy

## Mesajlaşma və Inteqrasiya

- SQS: Mesaj növbəsi (at-least-once)
- SNS: Bildiriş/Publish-Subscribe
- EventBridge: Hadisə bus-ı
- Step Functions: Orkestrasiya, state machine

## Təhlükəsizlik və Kimlik

- IAM: İcazələr, istifadəçi/rol/politika
- Cognito: İstifadəçi identiteti və federasiya
- KMS: Açar idarəsi və şifrələmə
- Secrets Manager / Parameter Store: Sirr idarəsi

## İzləmə və İdarəetmə

- CloudWatch: Metrika, log, alarmlar
- CloudTrail: API audit
- Config: Resurs konfiqurasiyasının izlənməsi
- X-Ray: Dağıdılmış tracing

## Analitika və ML

- EMR: Hadoop/Spark klasterləri
- Glue: ETL/xidmət kimi data kataloqu
- Athena: S3 üzərində serverless SQL
- Kinesis: Stream işləmə
- QuickSight: BI vizuallaşdırma
- SageMaker: ML model inkişafı və hostinq

## Migrasiya və Hibrid

- DMS: Məlumat köçürmə
- DataSync/Snow Family: Data transferi
- Outposts: On-prem üçün AWS aparatları

## Qısa Qərar Cədvəli

- API yazırsınız? → API Gateway + Lambda/ECS/EKS
- Fayl/obyekt saxlamaq? → S3 (+ Glacier arxiv)
- SQL lazımdır? → RDS/Aurora
- Açar-dəyər yüksək performans? → DynamoDB
- Keş? → ElastiCache
- Event-driven? → SQS/SNS/EventBridge
