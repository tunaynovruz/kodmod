# Register Allokasiyası

Məhdud sayda fiziki registrlərə IR-dəki sonsuz saylı virtual registrləri xəritələmək lazımdır. Məqsəd spill (stack-a atma) sayını və yüklənməsini minimallaşdırmaqdır.

## İki əsas yanaşma

- Qraf rəngləmə (Chaitin/Briggs/George-Appel): interference qrafı qurulur, k‑rəngləmə ilə registrlər verilir; coalescing ilə `mov`-lar azaldılır.
- Linear scan: live interval-lar vaxt oxunda sıralanır, aktiv dəst ilə sürətli qərarlar; JIT-lər və böyük koddəhlizləri üçün praktikdir.

```mermaid
flowchart LR
    A[IR (SSA)] --> B[Build liveness]
    B --> C{Select algo}
    C -- Coloring --> D[Interference graph]
    D --> E[Spill/coalesce/color]
    C -- Linear Scan --> F[Live intervals]
    F --> G[Allocate/spill]
    E --> H[Assign phys regs]
    G --> H
```

## Interference qrafı (Coloring)

- Düyün: virtual registr. Kənar: eyni anda canlı olan (interfere) cüt.
- Simplify: dərəcəsi < K olan düyünləri staka itələ.
- Spill seçimi: yüksək çəkili düyünlər (istifadə tezliyi / live uzunluğu) prioritetlə seçilir.
- Coalescing: `mov v1→v2` varsa və birləşdirmə rəngləməni pozmursa düyünləri birləşdir.

## Linear Scan

- Live interval: `[start, end)` — instruksiya nömrələrinə görə.
- Aktiv dəst: overlap edənlər; yeni interval gələndə boş registr yoxdursa ən az önəmlini spill et.
- Split/Spill: interval parçalanması ilə kritik hot hissələrdə spill-dən qaçmaq.

```c
// Pseudo: Linear Scan
for (v in intervals by start) {
  expire_old_intervals(v.start);
  if (active.size == K) spill_worst(active, v);
  else assign_free_reg(v);
}
```

## SSA və allokasiya

- SSA coalescing-i asanlaşdırır (phi-lar). Phi resolution: parallel copy-lər prolog/edge-lərdə yerləşdirilir.
- Copy coalescing ilə `phi` operandları eyni registrə xəritələnə bilər.

## Spill kodu

- Spill: `store v → [sp+off]`; reload: `load [sp+off] → v`.
- Prolog/epilog: frame quruluşu, callee-saved registrlərin saxlanması/bərpası.

## Praktika

- Hədəf ABI-nin caller/callee-saved qaydalarını gözləyin.
- Vector/FPU registr hovuzlarını ayrıca allokasiya edin.
- JIT-lərdə linear scan + interval split çox vaxt kifayətdir; AOT üçün coloring daha yaxşı kod verə bilər.
