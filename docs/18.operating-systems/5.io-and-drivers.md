# I/O və Sürücülər

I/O — disk, şəbəkə, terminal kimi cihazlarla data mübadiləsidir. OS bu əməliyyatları buffer-lərlə, DMA və sürücülərlə koordinasiya edir.

## Buffered vs Direct I/O

- Buffered: Kernel page cache istifadə edilir; ardıcıl oxu/yazı üçün sürətli.
- Direct (O_DIRECT): Cache-i ötür; stabil gecikmə üçün faydalıdır, amma düzgün align tələb edir.

## Async I/O modelləri

- readiness-based: select/poll → epoll (Linux), kqueue (BSD/macOS).
- completion-based: IOCP (Windows), io_uring (Linux) — tamamlanma hadisəsi gəlir.

```c
// epoll skeleti
int ep = epoll_create1(0);
struct epoll_event ev = {.events = EPOLLIN, .data.fd = sock};
epoll_ctl(ep, EPOLL_CTL_ADD, sock, &ev);
while (1) {
  int n = epoll_wait(ep, events, MAX, -1);
  // oxunacaq socket-ləri emal et
}
```

## DMA və sürücülər

- DMA: CPU-nu yükləmədən cihaz↔RAM köçürməsi.
- Drivers: cihazın idarə olunması üçün kernel moduludur; sysfs/devfs ilə interfeys.

## Praktik məsləhətlər

- Yüksək QPS serverlər üçün edge-triggered epoll, SO_REUSEPORT və sendfile istifadə edin.
- SSD-lərdə böyük dərinlikli (queue depth) async I/O throughput-u artırır.
- io_uring bəzi workload-larda sistem çağırışlarını azaldır və latency-ni stabilləşdirir.

## Internals (Daxili qatlar)

- Blok I/O yolu (storage):
  - libaio/io_uring → kernel I/O submission → block layer (elevator/qdisc) → driver → DMA → cihaz.
  - NVMe: multi-queue submission/completion queue-lar; CPU core-lar üzrə paylama (RSS-ə bənzər).
  - `bio`/`request` strukturları ilə I/O-lar birləşdirilə bilər (merge) və ya parçalanar (split).
- Şəbəkə I/O yolu:
  - RX: NIC → IRQ/MSI-X → NAPI poll → GRO → TCP/IP stack → socket recv queue.
  - TX: send buffer → TCP segmentation (TSO/GSO) → NIC → DMA → wire.
- DMA və IRQ:
  - DMA map/unmap (IOMMU varsa translation) → completion interrupt → üst səviyyə softirq işləyir.
- io_uring (Linux):
  - SQ (Submission Queue) + CQ (Completion Queue) ring buffer-ları; `io_uring_enter` ilə kernelə bildiriş.

```mermaid
flowchart LR
    A[User space: write()] --> B[libc/io_uring]
    B --> C[Syscall]
    C --> D[Block layer]
    D --> E[Driver]
    E --> F[DMA to disk/NIC]
    F --> G[Completion IRQ]
    G --> H[Softirq/NAPI]
    H --> I[Completion queue → userspace]
```

### Observability və Praktika
- `cat /sys/block/<dev>/queue/*` ilə block parametrlərinə baxın; `iostat -x` disk davranışı.
- `ethtool -S`, `ss -ti`, `nstat`, `tc -s qdisc` şəbəkə metrikləri.
- Yüksək QPS üçün `io_uring` və ya IOCP seçin; read/write birləşdirilməsi (coalescing) və batch.
