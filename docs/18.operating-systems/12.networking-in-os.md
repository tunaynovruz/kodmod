# OS daxilində Şəbəkə (Sockets)

Socket-lər kernel TCP/IP stack-ı ilə əlaqə üçün əsas interfeysdir. Performans və stabillik üçün düzgün konfiqurasiya həyati önəmlidir.

## Əsas API-lər

- `socket()`, `bind()`, `listen()`, `accept()` — server skeleti.
- `connect()`, `send()`, `recv()` — müştəri əməliyyatları.
- Non-blocking + `epoll/kqueue/IOCP` — yüksək miqyaslama.

```c
int s = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
bind(s, (struct sockaddr*)&addr, sizeof(addr));
listen(s, SOMAXCONN);
// epoll ilə accept/read döngüsü
```

## Bufferlər və backlog

- `SO_RCVBUF`/`SO_SNDBUF`: socket buffer ölçüləri; sysctl limitlərini yoxlayın.
- `listen()` backlog kernel accept queue üçün limitdir; SYN backlog ayrıca idarə olunur.

## Offloading və sürətləndirmə

- TSO/GSO, GRO/LRO: paketlərin birləşdirilməsi; CPU yükünü azaldır.
- RSS: multi-queue NIC-lərdə paketləri core-lara paylayır.
- NAPI: interrupt fırtınasının qarşısını alır; polling rejimi.
- Zero-copy: `sendfile()`, `splice()`, `MSG_ZEROCOPY` (Linux), `TransmitFile` (Windows).

## TCP parametrləri

- `TCP_NODELAY` (Nagle off) — kiçik mesajlarda gecikməni azaldır.
- Keepalive-lar — uzunmüddətli bağlantılar üçün faydalıdır.
- `SO_REUSEPORT` — çox prosess/thread ilə yük paylama.

## Təhlükəsizlik

- `iptables/nftables` (netfilter), Windows Firewall.
- SYN flood qarşısı: SYN cookies, backlog tənzimi.

## Praktika

- Accept döngüsündə backpressure: application queue doludursa `EPOLLRDHUP`/`EPOLLOUT` ilə nəzarət.
- Metrikləri toplayın: retransmits, cwnd, rtt; `ss -ti`, `netstat`, ETW/Perf Counters.

## Internals (Socket → Stack → NIC boru xətti)

- Accept path (server):
  - `listen()` iki sıra yaradır: SYN backlog (hələ tam qurulmamış TCP) və accept queue (tam qurulmuş).
  - `accept4()` accept queue-dan götürür; boşdursa `EAGAIN` (non-blocking) və ya bloklanır.
- RX path (gəliş):
  - NIC → IRQ/MSI-X → NAPI poll → GRO (paket birləşdirmə) → tcp_v4_rcv → socket recv buffer.
  - RFS/RPS: CPU/queue-affinity optimizasiyaları; `ethtool -l` multi-queue konfiqurasiyası.
- TX path (göndəriş):
  - `sendmsg()` → skbuff → qdisc (fq/codel, pfifo_fast) → driver → TSO/GSO → NIC DMA → wire.
- Netfilter hook-ları:
  - `PREROUTING` → `INPUT` → `FORWARD` → `OUTPUT` → `POSTROUTING`; iptables/nftables qaydaları bu keçidlərdə tətbiq olunur.
- Offloads:
  - Checksum offload, TSO/GSO (segmentləşdirməni NIC edir), GRO/LRO (birləşdirmə), XDP (very-early drop/redirect).
- Zero-copy:
  - `sendfile/splice`, `MSG_ZEROCOPY`, `mmap` + `PACKET_ZEROCOPY`; user→kernel copy azaldılır.

```mermaid
flowchart LR
    A[App: recv()] --> B[Socket recv queue]
    B --> C[TCP/IP stack]
    C --> D[GRO / reassembly]
    D --> E[NAPI poll]
    E --> F[NIC IRQ/MSI-X]
    F --> G[Hardware]

    H[App: send()] --> I[Socket snd buffer]
    I --> J[TCP segmentation / TSO]
    J --> K[qdisc (fq/codel)]
    K --> L[Driver]
    L --> M[NIC DMA]
    M --> G
```

### Observability və Praktika
- `ss -ti`, `nstat`, `ethtool -S`, `tc -s qdisc` ilə queue-ları və drop-ları izləyin.
- SYN backlog-da təzyiq: `tcp_max_syn_backlog`, `somaxconn` dəyərlərinə baxın; SYN cookies aktiv olsun.
- Multi-core miqyaslama: RSS/RPS ilə paketləri core-lar arasında paylayın; IRQ affinity (`/proc/irq/*/smp_affinity`).
