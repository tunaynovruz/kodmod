# Təhlükəsizlik və İzolyasiya

OS təhlükəsizliyi identifikasiya, icazələr və izoliyadan başlayır. Proqramçı olaraq minimal hüquqlar prinsipinə əməl edin.

## Kimlik və icazələr

- UID/GID: istifadəçi və qrup ID-ləri; effektif UID (setuid) anlayışı.
- Permissions: `rwx` bitləri, `umask`, default ACL-lər.
- ACL: incə dənəli icazələr; `getfacl/setfacl`.

## Capabilities

- Root-u hissələrə bölən mexanizm: `CAP_NET_BIND_SERVICE`, `CAP_SYS_ADMIN` (genişdir — ehtiyatlı olun).

## Mandatory Access Control

- SELinux/AppArmor: siyasət əsaslı məhdudiyyətlər; konteynerlər üçün əlavə qoruma.

## Syscall filtrləri

- seccomp-bpf: icazə verilən syscall siyahısını daraldın.

## Praktika

- Drop privileges: servis startdan sonra `setuid`/`setgid`.
- Chroot/jail ilə fayl sistemi görünüşünü məhdudlaşdırın.
- Gizli məlumatlar üçün `mlock` (swap-a çıxmaması üçün); `no_new_privs` bayrağı.

## Internals (cred, capabilities, LSM, seccomp)

- `cred` strukturu (Linux):
  - `uid/gid`, `euid/egid`, `fsuid/fsgid`, `cap_effective`, `cap_permitted`, `cap_bset` (bounding set), `securebits`.
  - `commit_creds(new)` ilə prosesin kimliyi dəyişdirilir; `prepare_creds()` nüsxə yaradır (copy-on-write kimi).
- Capabilities axını:
  - `cap_bset` bounding set-dən kənar capability əldə edilə bilməz.
  - Setuid binarilər və file capabilities (`setcap`) vasitəsilə effektif capability-lər formalaşır.
- LSM (Linux Security Modules) hook-ları:
  - `security_file_open`, `security_bprm_check`, `inode_permission` və s. — SELinux/AppArmor kimi modul­lar bu hook-larda qərar verir.
- SELinux (MLS/MCS):
  - Subyekt (process) və obyekt (file/socket) üçün `type`/`context`; siyasətə görə allow/deny.
- seccomp-bpf:
  - BPF filter ilə syscall nömrəsi və arqumentlərə əsaslanıb allow/errno/kill qaytarır.
  - `SECCOMP_MODE_FILTER` + `no_new_privs` ilə birləşdikdə güclü sandbox.

```mermaid
flowchart LR
    A[Syscall entry] --> B[seccomp BPF filter]
    B -->|deny| X[return -EPERM/KILL]
    B -->|allow| C[LSM hooks]
    C -->|deny| X
    C -->|allow| D[Subsystem (FS/NET/MM)]
    D --> E[Result]
```

### Praktika və Observability
- `capsh --print`, `cat /proc/$$/status` (CapEff) ilə capability-ləri görün.
- SELinux: `audit2allow` loglardan siyasət generasiyasında kömək edir.
- seccomp: `SCMP_ACT_LOG` ilə əvvəlcə müşahidə rejimi, sonra sərtləşdirmə; `strace` ilə lazımi syscall-ları toplayın.
