# Fenwick Tree (Binary Indexed Tree)

Fenwick Tree massiv üzərində prefix cəmlərini O(log n) vaxtda hesablamağa və tək element yeniləməsini O(log n) vaxtda etməyə imkan verir. Segment Tree-dən daha sadə və daha az yaddaş tutur.

Əməliyyatlar:
- update(i, delta): arr[i]-yə delta əlavə et
- prefixSum(r): [0..r] cəmini qaytar
- rangeSum(l, r) = prefixSum(r) − prefixSum(l−1)

## Java İmplementasiya

<details>
<summary>Koda bax</summary>

```java
public class FenwickTree {
    private final int n;
    private final long[] bit; // 1-based indeksləmə

    public FenwickTree(int n) {
        this.n = n;
        this.bit = new long[n + 1];
    }

    public FenwickTree(int[] arr) {
        this(arr.length);
        for (int i = 0; i < arr.length; i++) update(i, arr[i]);
    }

    // arr[idx] += delta
    public void update(int idx, long delta) {
        for (int i = idx + 1; i <= n; i += i & -i) {
            bit[i] += delta;
        }
    }

    // sum of arr[0..r]
    public long prefixSum(int r) {
        long res = 0;
        for (int i = r + 1; i > 0; i -= i & -i) {
            res += bit[i];
        }
        return res;
    }

    public long rangeSum(int l, int r) {
        if (l > r) return 0;
        return prefixSum(r) - (l == 0 ? 0 : prefixSum(l - 1));
    }
}
```
