# Segment Tree

Segment Tree massiv üzərində interval (range) sorğularını və yeniləmələri O(log n) vaxtda icra edən ağac strukturudur.

Tipik istifadə: Range Sum/Min/Max Query (RSQ/RMQ) və point update.

## Fikir
- Massiv elementlərini yarıya bölərək hər node-da alt intervalın cavabını saxlayırıq.
- Sorğu (l, r): yalnız üst-üstə düşən intervalların cavabları birləşdirilir.

## Java İmplementasiya (Range Sum)

<details>
<summary>Koda bax</summary>

```java
public class SegmentTree {
    private int n;
    private long[] tree; // 1-indexed tree massivində saxlayırıq

    public SegmentTree(int[] arr) {
        n = arr.length;
        int size = 1;
        while (size < n) size <<= 1; // tam ikinin qüvvəti
        tree = new long[size << 1];
        build(arr, 1, 0, n - 1);
    }

    private void build(int[] arr, int idx, int l, int r) {
        if (l == r) {
            tree[idx] = arr[l];
            return;
        }
        int mid = (l + r) >>> 1;
        build(arr, idx << 1, l, mid);
        build(arr, idx << 1 | 1, mid + 1, r);
        tree[idx] = tree[idx << 1] + tree[idx << 1 | 1];
    }

    // [ql, qr] aralığı üçün cəm
    public long query(int ql, int qr) {
        return query(1, 0, n - 1, ql, qr);
    }

    private long query(int idx, int l, int r, int ql, int qr) {
        if (qr < l || r < ql) return 0; // disjoint
        if (ql <= l && r <= qr) return tree[idx];
        int mid = (l + r) >>> 1;
        return query(idx << 1, l, mid, ql, qr) +
               query(idx << 1 | 1, mid + 1, r, ql, qr);
    }

    // arr[pos] = val
    public void update(int pos, int val) {
        update(1, 0, n - 1, pos, val);
    }

    private void update(int idx, int l, int r, int pos, int val) {
        if (l == r) {
            tree[idx] = val;
            return;
        }
        int mid = (l + r) >>> 1;
        if (pos <= mid) update(idx << 1, l, mid, pos, val);
        else update(idx << 1 | 1, mid + 1, r, pos, val);
        tree[idx] = tree[idx << 1] + tree[idx << 1 | 1];
    }
}
```

</details>

Qeyd: Min/Max üçün `+` yerinə uyğun birləşdirmə (min/max) istifadə edin. Lazy propagation yalnız range update-lər üçün lazımdır.
