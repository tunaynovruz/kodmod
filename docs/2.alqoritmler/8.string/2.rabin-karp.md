# Rabin–Karp

Fikir: P pattern-in uzunluğu m, T mətninin hər m uzunluqlu pəncərəsi üçün rolling hash hesabla. Hash-lar uyğun gələndə yalnız onda simvolları yoxla (collision üçün).

## Java İmplementasiya (polinomial rolling hash)

<details>
<summary>Koda bax</summary>

```java
import java.util.*;

public class RabinKarp {
    private static final long MOD = 1_000_000_007L;
    private static final long BASE = 911382323L % MOD; // böyük bazis

    public static List<Integer> search(String t, String p) {
        int n = t.length(), m = p.length();
        List<Integer> ans = new ArrayList<>();
        if (m == 0 || m > n) return ans;

        long[] pow = new long[n + 1]; pow[0] = 1;
        for (int i = 1; i <= n; i++) pow[i] = (pow[i-1] * BASE) % MOD;

        long[] pref = new long[n + 1];
        for (int i = 0; i < n; i++) {
            pref[i+1] = (pref[i] * BASE + t.charAt(i)) % MOD;
        }
        long ph = 0;
        for (int i = 0; i < m; i++) ph = (ph * BASE + p.charAt(i)) % MOD;

        for (int i = 0; i + m <= n; i++) {
            long win = (pref[i+m] - (pref[i] * pow[m]) % MOD + MOD) % MOD;
            if (win == ph) { // potensial uyğundur — collision ola bilər
                if (t.regionMatches(i, p, 0, m)) ans.add(i); // təsdiq et
            }
        }
        return ans;
    }
}
```

</details>

Qeyd: Collision riskini azaltmaq üçün iki modul ilə double-hashing istifadə oluna bilər.
