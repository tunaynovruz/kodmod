# KMP (Knuth–Morris–Pratt)

KMP, pattern P-ni mətn T-də O(n+m) vaxtda axtarır. Fikir: uyğunsuzluq olanda pattern-i sürüşdürərkən artıq uyğun gələn prefiksləri itirməmək üçün LPS (longest proper prefix which is also suffix) massivindən istifadə edirik.

## Java İmplementasiya

<details>
<summary>Koda bax</summary>

```java
import java.util.*;

public class KMP {
    private static int[] buildLps(String p) {
        int m = p.length();
        int[] lps = new int[m];
        for (int i = 1, len = 0; i < m; ) {
            if (p.charAt(i) == p.charAt(len)) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];
            } else {
                lps[i++] = 0;
            }
        }
        return lps;
    }

    // T-də P-nin başlanğıc indekslərini qaytar
    public static List<Integer> search(String t, String p) {
        List<Integer> res = new ArrayList<>();
        if (p.isEmpty()) return res;
        int[] lps = buildLps(p);
        for (int i = 0, j = 0; i < t.length(); ) {
            if (t.charAt(i) == p.charAt(j)) { i++; j++; }
            if (j == p.length()) { res.add(i - j); j = lps[j - 1]; }
            else if (i < t.length() && t.charAt(i) != p.charAt(j)) {
                if (j > 0) j = lps[j - 1]; else i++;
            }
        }
        return res;
    }
}
```

</details>
