# Fractional Knapsack

Hər əşyanın bir hissəsini götürməyə icazə verilir. Strategiya: dəyər/çəkİ nisbəti ən böyük olanı ilk götür.

## Java İmplementasiya

<details>
<summary>Koda bax</summary>

```java
import java.util.*;

public class FractionalKnapsack {
    static class Item { double w, v; Item(double w, double v){this.w=w; this.v=v;} }

    public static double maxValue(List<Item> items, double W){
        items.sort((a,b) -> Double.compare(b.v/b.w, a.v/a.w));
        double res = 0, cap = W;
        for (Item it : items) {
            if (cap <= 0) break;
            double take = Math.min(cap, it.w);
            res += (it.v / it.w) * take;
            cap -= take;
        }
        return res;
    }
}
```

</details>
