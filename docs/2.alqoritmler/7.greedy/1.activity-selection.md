# Activity Selection (Interval Scheduling)

Qayda: Ən tez bitən fəaliyyəti seç, sonra onunla uyğun olan növbətisini seç.

## Java İmplementasiya

<details>
<summary>Koda bax</summary>

```java
import java.util.*;

public class ActivitySelection {
    static class Interval { int s, f; Interval(int s,int f){this.s=s;this.f=f;} }

    public static List<Interval> select(List<Interval> a){
        a.sort(Comparator.comparingInt(x -> x.f));
        List<Interval> res = new ArrayList<>();
        int lastFinish = -1_000_000_000;
        for (Interval it : a) {
            if (it.s >= lastFinish) {
                res.add(it);
                lastFinish = it.f;
            }
        }
        return res;
    }
}
```

</details>

Düzgünlük intuissiyası: ən tez bitən fəaliyyət gələcək üçün maksimum boş vaxt saxlayır (exchange argument).
