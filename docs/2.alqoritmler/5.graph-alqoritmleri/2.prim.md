# Prim (MST)

Prim alqoritmi bağlı, yönsüz və çəkili qrafda Minimum Spanning Tree (MST) qurur. İdeya: böyüyən ağaca ən ucuz kənarı əlavə etmək.

## Java İmplementasiya (Adjacency List)

<details>
<summary>Koda bax</summary>

```java
import java.util.*;

public class PrimMST {
    static class Edge { int to; int w; Edge(int t,int w){this.to=t; this.w=w;} }

    // n: düyün sayı, g: qonşuluq siyahısı
    public static int prim(int n, List<List<Edge>> g) {
        boolean[] inMST = new boolean[n];
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
        // [vertex, weight]
        pq.add(new int[]{0, 0});
        int taken = 0, total = 0;
        while (!pq.isEmpty() && taken < n) {
            int[] cur = pq.poll();
            int u = cur[0], w = cur[1];
            if (inMST[u]) continue;
            inMST[u] = true; taken++; total += w;
            for (Edge e : g.get(u)) if (!inMST[e.to]) pq.add(new int[]{e.to, e.w});
        }
        if (taken != n) throw new IllegalStateException("Qraf bağlı deyil");
        return total;
    }
}
```
